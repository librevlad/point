# Умения телефона, у которых нет пары на компьютере (#1379).
#
# Решение владельца 01.09.2026: «пк должен все уметь не хуже телефона». Список — не разрешение
# на разрыв, а требование назвать его вслух: сторож `PhoneOnlyActionsDoNotGrowTest` не даёт ему
# расти молча и роняет сборку, когда на телефоне заводят умение, о котором компьютер не узнает.
#
# Строка уходит отсюда, когда умение появляется на компьютере. Добавлять строку можно только
# вместе с причиной, которую прочитает следующий человек.

# --- Результат зависит от места: у компьютера своё умение под своим именем.
# Конституция: «печать на телефоне и печать на компьютере — разные действия, потому что
# бумага выходит в разных местах».
open            # у компьютера pc-open — окно открывается там, где человек сидит
open-url        # у компьютера pc-open-link
open-in         # выбор приложения телефона
save            # у компьютера pc-save-as
save-all        # то же для набора
copy            # у компьютера pc-copy
copy-card       # кладёт в буфер того устройства, где человек смотрит
read-qr         # кладёт цифры кода в буфер этого устройства
share           # системное «Поделиться» телефона
share-all       # то же для набора
phone-apps      # список приложений телефона
pc              # «На компьютер»: с компьютера на компьютер не отправляют

# --- Отдаёт объект приложению телефона.
# На компьютере такое действие возможно (почта, карты, календарь браузером), но его ещё
# не делали — отдельная карточка, а не отказ.
call            # звонок с телефона
sms             # сообщение с телефона
email           # письмо приложением телефона
map             # карта приложением телефона
event           # событие в календаре телефона
save-contact    # контакт в книгу телефона
vcard           # то же карточкой контакта

# --- Волна 2: нативная обработка кадра.
# Карточка #1379: «нативным нужны JVM-собратья, не вынос» — OpenCV AAR, Bitmap, сегментация.
scan            # выравнивание страницы, OpenCV
scan-plus       # то же с цветом
scan-pdf        # то же страницами в PDF
cutout          # вырезать объект, сегментация
blur-bg         # размыть фон
replace-bg      # заменить фон
hide-area       # замазать область, Bitmap
take-fragment   # вырезка из кадра, Bitmap
shoot-more      # снять ещё страницу камерой телефона
merge-pdf       # картинки в PDF собирает Android PdfDocument; на компьютере нужен pdfbox
clean-metadata  # «Очистить метаданные»: снимок пересобирается Bitmap телефона

# --- Волна 1 не завершена: работа чистая, руки не дошли.
# Эти умения android-кода не требуют и на компьютере возможны тем же кодом, что на телефоне.
speak           # «Озвучить»: голос — орган устройства, а исполнитель чистый (TextToSpeech за швом)
