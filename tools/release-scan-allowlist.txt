# Release-эталон для tools/release-scan.sh (#306).
#
# Здесь перечисляются ТОЧНЫЕ строки, которые совпадают с секретными формами
# (AIza…, gh[pousr]_…, sk-…), но секретами не являются и законно живут в
# release-артефакте — например, случайная последовательность байт в шрифте или
# нативной библиотеке, распечатавшаяся как «sk-…».
#
# Правила:
#   * по одной строке на запись, сравнение точное (вся строка целиком);
#   * каждая запись — с комментарием строкой выше: откуда она и почему безобидна;
#   * живой ключ сюда не вносится НИКОГДА — он отзывается и перевыпускается;
#   * файл публичен по определению: всё, что в нём, уже лежит в раздаваемом артефакте.
#
# Сейчас эталон пуст: проверенные release-артефакты (APK v0.2.x, desktop-MSI)
# не содержат ни одного совпадения. Появится безобидное — впиши его сюда с причиной,
# и скан снова станет зелёным, не ослабляя правило для всего остального.
