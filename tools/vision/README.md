# Харнесс зрячих моделей: разметить → прочитать → сверить → посчитать

Отвечает на один вопрос числом, а не мнением: **сколько даёт комбинация моделей поверх
одиночного прогона** на настоящих документах владельца.

Проверяется тезис владельца (03.08.2026): «скормить документы зрячим моделям хорошо, но с
правильной разметкой (моделями же) и промптами получится идеально, надо только скомбинировать».

## Три способа, которые меряются РЯДОМ

| Способ | Что происходит | Зачем меряем |
|---|---|---|
| `whole` | картинка целиком → модель → текст | база сравнения: нынешний потолок |
| `parts` | модель-разметчик находит блоки и ячейки → каждый фрагмент режется → модель-читатель получает **фрагмент** и свой промпт под тип поля | тезис владельца |
| `agree` | спорные фрагменты читает вторая модель; расхождение — сигнал, а не ошибка | цена уверенности |

Смешивать их в одно число нельзя — это три разных обещания человеку.

Размер документа взят из жизни: обычная ведомость — одна-две страницы, тридцать строк. При таком
размере дорогой путь применяется **по умолчанию**, а не как эскалация: два-три десятка обращений
на документ влезают в бесплатные квоты с запасом.

## Как запускается

Кадры лежат вне репозитория (личные документы владельца), путь передаётся аргументом — харнесс
сам по чужим папкам не лазит.

```bash
python tools/vision/run.py --frames <папка с кадрами> --way parts --provider <имя> --out <каталог прогона>
python tools/vision/score.py --run <каталог прогона> --expected tools/corpus/23.expected.tsv
```

Провайдеры описываются в `providers.json` (ключи — из окружения, не в файле). Список живых
провайдеров и их лимиты собирает разведка; здесь — только то, как их дёргать.

## Правила, которые здесь не обсуждаются

- **Дословно.** Харнесс кладёт то, что вернула модель, без подчистки. Красивый отчёт по
  подчищенному выводу — самообман.
- **Каждый прогон принадлежит своему прогону.** Числа не переписываются задним числом, как и в
  `docs/CORPUS.md`.
- **Приватность — граница.** Кадр уезжает в чужой сервис только когда прогон запущен человеком
  явно, и в отчёте написано, **куда** он уехал. Военная ведомость и карта — не тестовые данные
  для чужого облака.
- **Провал называется провалом.** Если способ не дал результата — так и пишется, вместе с тем,
  что именно вернула модель.
