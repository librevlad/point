# /todo — мгновенный захват задачи в Issues

Владелец роняет мысль на ходу, пока крутится другая работа. Задача скилла —
**не потерять её и не сбить текущий поток**: превратить текст в аккуратный issue,
повесить на доску, отдать ссылку, вернуться к делу. Скоуп/приоритет/acceptance —
потом (это домен ко-фаундера, см. `docs/OPERATING-MODEL.md`).

## Инварианты
- **Не перебивай текущую работу.** Один заход: создал issue → добавил на доску →
  одна строка отчёта → продолжил прерванное. Не переключайся на выполнение новой
  задачи, не расширяй её, не задавай вопросов (единственное исключение — текст пуст).
- **Статус по умолчанию — `Backlog`.** Приоритет («Up next») ставит только
  человек/ко-фаундер. Claude никогда не двигает задачу выше Backlog сам.
- **Не полагайся на auto-add.** Встроенный воркфлоу борда сейчас НЕ подхватывает
  новые issues автоматически — поэтому скилл сам явно добавляет issue на Project #2.
- **Не глотай ошибку.** Если `gh` упал (auth/сеть) — честно скажи и покажи исходный
  текст задачи дословно, чтобы мысль не потерялась.

## Из текста — в issue
- **Title** — императив, по-русски, ≤ ~70 симв., без точки в конце
  («Починить классификацию в/ч», не «надо бы починить в/ч когда-нибудь»).
- **Body** — исходный текст владельца дословно + строка происхождения. Не выдумывай
  acceptance — это триаж ко-фаундера.
- Несколько задач в одном `/todo` (перевод строки / «и») → отдельный issue на каждую.
- Лейблы не навешивай (их ставит ко-фаундер), кроме явного маркера в тексте:
  «баг: …» → `--label bug`.

## Команды (Bash / gh; один заход)
Подставь TITLE и BODY. Константы борда зашиты (Project #2 «Point»).

```bash
PROJECT_ID=PVT_kwHOAvE9d84BeN3K
STATUS_FIELD=PVTSSF_lAHOAvE9d84BeN3KzhYpurw
BACKLOG=da9a91d0

URL=$(gh issue create --repo librevlad/point --title "TITLE" --body "BODY") \
  || { echo "gh issue create FAILED — задача НЕ потеряна: TITLE"; exit 1; }
ITEM=$(gh project item-add 2 --owner librevlad --url "$URL" --format json \
  | python -c "import sys,json;print(json.load(sys.stdin)['id'])")
gh project item-edit --id "$ITEM" --project-id "$PROJECT_ID" \
  --field-id "$STATUS_FIELD" --single-select-option-id "$BACKLOG" >/dev/null
echo "$URL"
```

Body-шаблон:
```
<дословный текст владельца>

—
Захвачено через /todo по ходу другой работы. Скоуп/acceptance — за ко-фаундером.
```

## Отчёт (ровно одна строка) и возврат
После успеха — одна строка, затем сразу продолжай прерванное дело:

`📌 #<N> <title> → <url> (Backlog)`

Несколько задач → по строке на каждую. Больше ничего не пиши, к новой задаче не
приступай.
