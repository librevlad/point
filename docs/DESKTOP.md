# Point для ПК — что умеет и как включить

Компьютер — не витрина телефона, а второе место, где живёт тот же объект. Часть работы там даже
удобнее: большой экран, принтер, папки, буфер обмена, и всё это под рукой.

Сверка **06.08.2026**.

## Девятнадцать действий

**С файлом как с файлом** — были с самого начала:

| Действие | Что делает |
|---|---|
| Открыть | системным приложением |
| Показать в папке | проводник с выделенным файлом |
| Скопировать | текст объекта в буфер компьютера |
| Сохранить как… | диалог сохранения |
| Напечатать | на принтер по умолчанию, без диалога |
| Скачать видео | по ссылке, через `yt-dlp` |
| На телефон | объект уезжает в круг устройств |
| Сделать PDF | из офисного документа, силами установленного Office |

**С содержимым** — появились в #585:

| Действие | Что делает | Нужен ключ |
|---|---|---|
| Найти в тексте | телефоны, почты, ссылки, суммы, даты, карты — списком | нет |
| Достать текст | docx, xlsx, pptx → текст, без Word | нет |
| Распаковать | zip рядом с архивом, папка открывается | нет |
| Открыть в браузере | для объекта-ссылки | нет |
| Сделать QR | ссылку — на экран телефона, без сети | нет |
| Сделать легче | картинка до 1920 по длинной стороне | нет |
| Дать ссылку | файл на сервер, ссылка в буфер, живёт сутки | вход в аккаунт |
| Понять | суть, суммы, даты, контакты | `ai.key` |
| Перевести | на русский, а русский — на английский | `ai.key` |
| Спросить AI | свободный вопрос по тексту | `ai.key` |
| Расшифровать | речь → текст | `speech.key` |

## Четыре входа

1. **Перетащить** файл в окно.
2. **Взять из буфера** — `Ctrl+Shift+V`.
3. **Снять экран** — `Ctrl+Shift+S`. Окно Point прячется на миг, снимается весь экран (все
   мониторы). Того, что сейчас на экране, нет ни в одном файле — и это самое частое на компьютере.
4. **Поделиться с телефона** — объект приезжает через круг устройств.

## Настройка: `~/.point-pc/config`

Обычный текстовый файл, по строке на запись. Ключи живут **только здесь** и в раздаваемый
установщик не попадают никогда.

```
name=Рабочий ноутбук
server=

# AI: понять, перевести, спросить. Любая OpenAI-совместимая ручка.
ai.key=sk-or-v1-…
ai.url=https://openrouter.ai/api/v1/chat/completions
ai.model=meta-llama/llama-3.3-70b-instruct:free

# Расшифровка речи — ключ ДРУГОГО сервиса: у OpenRouter такой ручки нет вовсе.
speech.key=gsk_…
speech.url=https://api.groq.com/openai/v1/audio/transcriptions
speech.model=whisper-large-v3
```

Строки `url` и `model` необязательны — без них берутся значения выше. **Нет ключа — нет и
действия:** оно уезжает на телефон помеченным «недоступно», и кнопки там не появляется. Это лучше,
чем кнопка, которая молчит.

## Что компьютер делать не станет

**Читать текст с фотографии.** Tesseract — Android-библиотека, на ПК её нет. Снимок несут на
телефон, где цепочка чтения построена и замерена (`docs/VISION-MODELS.md`).

**Спрашивать зрячую модель картинкой.** По совместимой ручке часть провайдеров молча отвечает
текстом «я не вижу изображения» — это выглядит как ответ, а не как отказ. Пока компьютер честно
говорит, что не умеет.

**Открывать rar и 7z.** Штатная JVM знает zip; ради двух форматов чужая библиотека в образ не
тянется. Действие говорит об этом прямо.

## Сборка и запуск

```bash
export JAVA_HOME="C:/Program Files/Android/Android Studio/jbr"
./gradlew :desktop:run                     # запустить из исходников
./gradlew :desktop:packageMsi              # установщик Windows
./gradlew :desktop:test                    # 107 тестов, без сети и без экрана
```

Модуля `jdk.httpserver` в образе больше нет: он держался ради приёмника локальной сети, которой у
Point не осталось (#475). Входящих соединений компьютер не слушает вовсе — и запроса брандмауэра
при первом запуске больше не бывает.
