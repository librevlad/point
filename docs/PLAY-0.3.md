# Закрытый тест 0.3 в Google Play

Что машина уже проверила и что остаётся человеку. Не пересказ политики магазина — только то,
что относится к этой сборке и проверено на ней.

## Что уезжает

| | |
|---|---|
| Пакет | `com.point` |
| Версия | `versionName 0.3.0`, `versionCode 3` |
| Что грузить в Play | `app/build/outputs/bundle/release/app-release.aab` |
| SDK | `minSdk 26`, `targetSdk 36`, `compileSdk 36` |
| Размер | бандл ≈ 37 МБ (APK того же кода ≈ 58 МБ) |

APK из ассетов GitHub-релиза в Play **не** идёт: там подпись другая и назначение другое.
В Play уходит только бандл.

## Устройства

В сборке лежит одна нативная архитектура — `arm64-v8a`. Библиотек под `armeabi-v7a` не
поставляет ни одна из зависимостей (движок распознавания, OpenCV), поэтому 32-битные
устройства Play в закрытый тест не пустит. Строка `armeabi-v7a` в `abiFilters` осталась
намеренно — как память о намерении; фактического действия у неё сегодня нет.

## Разрешения — что отвечать в Play Console

Своих у Point четыре, и каждое просится по тапу человека, а не на старте:

- `ACCESS_FINE_LOCATION` + `ACCESS_COARSE_LOCATION` — источник «Место» в шторке. Фонового
  доступа нет.
- `RECORD_AUDIO` — источник «Голос»: Point пишет сам, потому что диктофона на телефоне может
  не быть.
- `VIBRATE` — отклик в руку на «получилось / не вышло».

Остальные пришли с библиотеками, и Point ими сам не пользуется:

- `INTERNET`, `ACCESS_NETWORK_STATE` — сеть;
- `WAKE_LOCK`, `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE` — WorkManager, который тянет за
  собой ML Kit (`entity-extraction`). Своих Worker'ов в Point нет ни одного.

`FOREGROUND_SERVICE` магазин спрашивает отдельно. Ответ честный: сервис принадлежит
WorkManager и запускается им; Point не объявляет ни одного собственного.

## Что машина проверила на этой сборке

- собраны только release-варианты; `debuggable` в манифесте нет;
- отладочных поверхностей (`SandboxActivity`, `PrintProbeActivity`) нет ни в APK, ни в бандле;
- скан секретных форм по содержимому APK и бандла — чисто (`tools/release-scan.sh`);
- `local.properties` вне истории git;
- минификация и сжатие ресурсов включены, сборка с ними проходит.

Проверяется одной командой:

```bash
bash tools/release-gate.sh          # со сборкой
bash tools/release-gate.sh --no-build
```

## Что остаётся человеку

1. **Подписать.** Ключа загрузки нет ни в репозитории, ни в CI — он только у владельца.
   `RELEASE_STORE_FILE` и пароли живут в `local.properties`; без них сборка подписывается
   отладочным ключом, и ворота её не пропускают — это и есть проверка, что ключ на месте.
   ```bash
   ./gradlew :app:bundleRelease
   bash tools/release-gate.sh --no-build   # ждём PASS
   ```
2. **Загрузить бандл** в Play Console → закрытый тест, добавить список тестеров.
3. **Заполнить в консоли** то, чего нет в коде: описание, скриншоты, категория, ответы
   Data safety (см. разделы про разрешения и обещания выше), возрастной рейтинг.
4. **Смоук на устройстве** — на релизной сборке, а не на отладочной: минификация включена
   только в ней, и ломается тоже только она.

## Чего в этой сборке сознательно нет

- вес и холодный старт (#539) — отложено владельцем;
- модульная установка движка распознавания (#23, #24) — отложено;
- постквантовая криптография Bouncy Castle (≈8 МБ), которой Point не пользуется, приезжает
  транзитивно и в бандле остаётся.
