# Point в Google Play — закрытое тестирование

Всё, что нужно для первой загрузки в консоль, и честная граница: **что сделано в репозитории** и
**что может сделать только владелец** (у него аккаунт разработчика, его подпись, его решение).

Сверено с кодом 05.08.2026. Версия к загрузке — **0.3.0 (versionCode 3)**.

## Готово в репозитории

| Требование магазина | Состояние |
|---|---|
| Формат загрузки — AAB | `./gradlew :app:bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`, 37,5 МБ |
| Подпись релизным ключом | ключ в `C:/Users/User/.point-keys/point-release.jks`, путь и пароли — в `local.properties` |
| `targetSdk` не ниже прошлогоднего | 36 (Android 16) |
| Поддержка 16 КБ страниц памяти | все 9 нативных библиотек выровнены на 16384 — проверено чтением ELF |
| Ни одного секрета в артефакте | `bash tools/release-gate.sh` — скан репозитория, артефакта и отладочных поверхностей |
| Удаление аккаунта **в приложении** | «Мои устройства» → «Удалить аккаунт» → «Удалить навсегда» |
| Удаление аккаунта **веб-страницей** | `https://point.leerio.app/delete-account` |
| Политика конфиденциальности | `https://point.leerio.app/privacy` |
| Разрешения объяснимы | всего два: микрофон (расшифровка речи), точное место (координаты в объекте) |

**Обе страницы живут в сервере** (`relay/point_server/pages.py`) и покрыты тестами: открыты без
пропуска, не тянут ни одного чужого домена, называют способ удаления и то, что после него
остаётся. Требуют выкладки сервера — см. «Что делает владелец».

```
Point отвечает на один вопрос: что я могу сделать с этим объектом прямо сейчас?

Поделитесь в Point фотографией, документом, текстом, ссылкой или архивом — и вместо меню
настроек увидите список того, что с ним можно сделать. Выбрали действие — получили новый
объект, и снова видите, что можно сделать уже с ним.

Что умеет:

• Прочитать текст с фотографии — прямо на устройстве, без интернета.
• Разобрать документ: PDF, Word, Excel, презентацию, архив.
• Найти в тексте телефоны, адреса, суммы, даты — и сразу позвонить, открыть карту, добавить в
  календарь.
• Превратить одно в другое: фотографию в PDF, таблицу в файл, речь в текст.
• Передать объект на свой компьютер и обратно — через ваш аккаунт, без проводов и настроек.
• Отправить файл человеку без Point — одной ссылкой, которая живёт сутки.

Чего в Point нет:

Ни ленты, ни списка задач, ни чата, ни настроек, которые надо изучать. Нет и автоматических
цепочек: каждое действие — ваш выбор, Point ничего не делает за вас сам.

О ваших данных:

Разбор идёт на самом устройстве. Если действию нужен чужой сервис — Point говорит об этом на
том же экране, где спрашивает, и ждёт вашего нажатия. До нажатия наружу не уходит ничего.

Удалить аккаунт и всё, что лежит на сервере, можно в один шаг: Мои устройства → Удалить
аккаунт.
```

**Категория:** Инструменты (Tools) · **Тип:** приложение · **Платно/бесплатно:** бесплатно,

## Анкета «Безопасность данных» (Data safety)

Отвечать по этой таблице — она сверена с кодом сервера, а не сочинена.

**Собираются ли данные?** Да. **Шифруются ли при передаче?** Да (HTTPS).
**Может ли пользователь запросить удаление?** Да.

| Тип данных | Собирается | Зачем | Обязательно | Передаётся третьим |
|---|---|---|---|---|
| Почта | да | вход в аккаунт, узнавание устройств | да, для аккаунта | нет |
| Имя | да | показ владельца аккаунта | да, для аккаунта | нет |
| Файлы и документы | да, **временно** | передача между вашими устройствами; хранится до получения, зашифровано ключами устройств | нет | нет |
| Фото и видео | да, **временно** | то же — передача между вашими устройствами | нет | нет |
| Идентификаторы устройства | да | круг устройств, отзыв доступа | да, для аккаунта | нет |

**Не собирается:** местоположение, контакты, календарь, история звонков и сообщений, состояние
здоровья, платёжные данные, история просмотров, статистика поведения, рекламные идентификаторы.

Разрешения **микрофон** и **точное место** используются на устройстве и на сервер не отправляются:
речь расшифровывается для объекта, координаты попадают в сам объект, который остаётся у человека.

**Про чужие сервисы.** Действия, которые выполняет внешний сервис (чтение сложной фотографии,
ответ модели), запускаются только явным нажатием и не входят в сбор данных приложением: объект
уходит по решению человека и в тот сервис, который назван на экране. В анкете это отражено как
«данные не передаются третьим лицам» для собираемых типов — потому что собранное Point (почта,
имя, идентификаторы) не передаётся никому.

## Проверка перед каждой загрузкой

```bash
bash tools/release-gate.sh
```

Чистое дерево → релизная сборка → скан репозитория → скан артефакта по **фактическим** значениям
секретов → скан отладочных поверхностей → PASS/BLOCKED. Ворота стоят до публикации, а не после:
ключ, уехавший в магазин, отзывается сменой ключа, а не удалением сборки.
